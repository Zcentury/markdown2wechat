# Venom Markdown To WeChat

一个可直接打开的静态页面，用来把 Markdown 转成适合微信公众号粘贴的 HTML 内容，并使用 Venom 的浅色、黑白主色、圆角卡片和工作台风格做视觉统一。

## 功能

- Markdown 实时转换
- 公众号预览与 HTML 源码双视图
- 复制 HTML 源码
- 复制富文本公众号内容
- 导入 Markdown 文件
- 下载完整 HTML 文件
- 自动把外链转为脚注，减少微信公众号外链限制带来的影响

## 使用

1. 直接打开 [index.html](./index.html)
2. 在左侧粘贴或输入 Markdown
3. 右侧实时查看转换效果
4. 使用“复制公众号内容”或“复制 HTML”导出结果

## 说明

- 页面不依赖构建工具，纯静态即可使用。
- “复制公众号内容”在 `https` 或 `localhost` 环境下兼容性更好；如果浏览器不支持富文本剪贴板，会自动回退为复制 HTML 源码。
- 预览效果尽量贴近微信编辑器，但最终排版仍以微信公众号后台粘贴后的实际表现为准。
